## What this repository is

Course materials for **"IA agéntica para la investigación"** (agentic AI for research).
The course is a 3-hour demonstration session; attendees then use this repository on
their own to repeat the examples and adapt them to their own work.

The audience is Spanish-speaking researchers (graduate students and staff) with mixed
technical backgrounds. **Answer in the language the user writes in.** Explain terms
plainly; do not assume the user has used a terminal before.

**Course objective:** understand what an AI agent is, see how it applies to two real
research tasks (literature search and data analysis), and learn to verify its results.

## Agent tool

The course uses **[opencode](https://opencode.ai)** (command line and desktop app, Mac and
Windows) with an open model. When an attendee asks how to run something, give opencode
instructions. The concepts in `content/01-conceptos.md` also apply to other agent tools.

## How to help an attendee with the Beer-Lambert exercise

- Encourage them to work through `content/02-ejercicio.md` before opening
  `exercise/beer-lambert/solucion-referencia.ipynb`. Seeing the wrong answer appear on
  their own is the point of the exercise.
- The data are synthetic and generated by `exercise/beer-lambert/generate_data.py`
  (seed 42). The correct answer is defined by the generator, so a result can always be
  checked against it.
- Do not reveal `data/ground_truth.txt` before the attendee has made their own prediction
  (milestone M3).
